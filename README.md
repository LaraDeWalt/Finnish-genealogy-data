# Finnish Genealogy Data

A data-driven genealogy project combining Finnish historical records into a structured and searchable database for research, analysis and visualization.

## About the project

Finnish historical records contain a large amount of information about people, families, households, occupations and places. Much of this information is available in digitized archival sources, but using it for larger-scale research often requires manual interpretation and combining information from several different records.

The aim of this project is to explore how historical Finnish genealogical data can be transformed into structured relational data that can be searched, analyzed and eventually visualized geographically.

The project currently focuses on historical records from Kainuu, particularly the Puolanka area.

## Data sources

The project is designed around information found in historical Finnish sources such as:

- population and taxation records (henkikirjat)
- communion and household examination books (rippikirjat)
- birth, marriage and death records
- historical maps and place information

Source references and uncertainty will be preserved as part of the data model whenever possible.

## Data model

The database is being designed to represent historical information including:

- persons
- names and patronymics
- families and relationships
- households
- farms, crofts and other places
- occupations and social status
- residence over time
- source references
- historical events and observations

A key challenge is that people, household structures and place names change over time. The data model therefore aims to separate persons, places and source observations instead of treating historical records as a single static family tree.

## Project goals

The long-term goal is to build a system that can:

- store historical genealogical information in a relational database
- connect the same individuals across different archival sources
- follow people and families through time and between locations
- search people, households and places
- analyze historical population and migration patterns
- visualize historical data on maps
- support genealogy and local-history research

## Technologies

The project is also a practical learning project in data and software development.

Planned technologies include:

- SQL
- Python
- relational database design
- Git and GitHub
- data cleaning and transformation
- data analysis
- geographical data and visualization

Additional technologies will be added as the project develops.

## Current status

🚧 **Early development**

The database structure and data model are currently being designed. Initial historical records are being manually interpreted and structured before larger-scale data processing and analysis are introduced.

## Why this project?

This project combines genealogy, historical research and data analysis.

Besides its research purpose, it serves as a portfolio project demonstrating practical skills in data modelling, structured problem solving, SQL, Python and analytical thinking.
